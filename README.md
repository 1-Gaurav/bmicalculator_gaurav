 BMI Calculator ⚖️

A simple **BMI (Body Mass Index) Calculator** built using **HTML, CSS, and JavaScript**.  
This project calculates BMI based on the user's height and weight and shows the health category.

🚀 Features
- Input height (cm) and weight (kg).
- Calculates BMI instantly.
- Displays BMI value and health category:
  - Underweight
  - Normal weight
  - Overweight
  - Obese
- Simple, clean, and responsive design.

 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
